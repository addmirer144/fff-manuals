  • 각 팀이 자기 역할에 집중할 수 있도록 팀 간 연결과 조정에 집중한다
  • 행사의 톤은 "축제"가 아니라 "환대" — 시끌벅적보다 따뜻하게 흐르도록 한다
  • 당일 예기치 못한 상황에서는 기획팀이 최종 판단권을 행사한다

6 사전 준비 체크리스트

D-14 (2주 전)

  • 각 팀 팀장 확정 및 인원 배치 완료 여부 확인
  • 예산 집행 현황 점검 (잔여 예산 확인)
  • 전체 타임라인 최종 확정 및 각 팀 공유
  • 초대장 발송 현황 확인 (홍보팀과 공유)
  • 기도카드 제작·배포 현황 확인

D-7 (1주 전)

  • 각 팀 준비 현황 취합
  • 접수 장소·동선 최종 확정 (안내팀·새가족팀과 공유)
  • 4층 소망채플 사진관 준비 상태 확인 (교육팀)
  • 애찬 메뉴·수량 확인 (주방팀)
  • 홍보물 설치 계획 확인 (홍보팀)
  • 예배 순서·찬양 확인 (예배찬양팀)

D-1 (전날)

  • 각 팀장에게 최종 확인 연락
  • 당일 변경 사항 정리 및 공유
  • 비상 연락 체계 최종 확인
  • 물품 준비 상태 확인 (접수 용품, 쿠폰, 기도카드 등)

7 시간대별 상세 동선

10:00~10:30 — 집결·전체 점검

  • 기획팀 전원 1층 로비 집결
  • 각 팀 팀장 출석 확인 — 미도착 팀장에게 연락
  • 5개 공간 순회 점검:
    • 1층 로비: 접수 테이블, 포토존 준비 상태
    • 주차장·입구: 안내 표지판, 차량관리팀 배치
    • 사랑채플(예배실): 좌석 배치, 음향·영상 점검
    • 3층: 애찬 준비 상태, 기도카드 전시
    • 4층 소망채플: 사진관 셋업 완료 여부
  • 각 팀 준비 완료 보고 취합
  • 당일 변경 사항 있으면 관련 팀에 즉시 전달

10:30~10:55 — 초청 가족 도착·흐름 관찰

  • 1층 로비에서 접수 흐름 관찰
  • 접수 대기줄이 길어지면 안내팀에 인원 보강 요청
  • 초청 가족 도착 규모 파악 — 예상보다 많으면 애찬·사진관에 사전 전달
  • 각 팀이 자기 위치에 배치되어 있는지 확인
  • 10:50까지 예배 준비 완료 상태 확인

11:00~12:00 — 예배 중

  • 예배 흐름 모니터링 (로비 또는 예배실 후방에서)
  • 늦은 도착 초청 가족 규모 파악
  • 꽃 전달·기도카드 순서 진행 시 동선 확인
  • 예배 후 전환 준비 — 단체사진 촬영 방식 최종 확인
  • 사진관·애찬 운영팀에 "예배 종료 10분 전" 사전 알림

12:00~12:30 — 예배 후 전환 (가장 혼잡)

  • 단체사진 촬영 진행 확인
  • 4층 사진관·3층 애찬 동시 이동 흐름 관찰
  • 계단·엘리베이터 혼잡 시 안내팀과 즉시 소통
  • 초청 가족이 다음 단계(사진·애찬)로 자연스럽게 연결되는지 확인
  • 비어 있는 공간이 있으면 활용 방안 즉석 판단

12:30~13:00 — 애찬·마무리

  • 3층 식사 흐름 확인 — 초청 가족 배려 상태 점검
  • 사진관 마감 시간 확인 (교육팀)
  • 귀가 시작하는 초청 가족 흐름 관찰
  • 새가족팀 접수 명단 1차 수합 여부 확인

13:00~13:30 — 정리·철수·평가

  • 각 팀 정리 상황 확인
  • 원상복구 완료 여부 순회 점검
  • 새가족팀에서 접수 자료 교역자 전달 확인
  • 특이사항·개선점 간단 메모
  • 담임목사님께 당일 운영 결과 간략 보고
  • 1주일 이내 평가 미팅 일정 확정

상황멘트
팀장 집결 시"오늘 잘 부탁드립니다. 각 위치에서 준비 완료되면 알려주세요."
접수 혼잡 시"접수 대기가 길어지고 있습니다. 안내팀에서 인원 하나 보충해 주실 수 있을까요?"
예배 후 전환 시"사진관은 4층, 식사는 3층입니다. 동선이 겹치지 않도록 안내 부탁드립니다."
비상 판단 시"이 부분은 제가 결정하겠습니다. 우선 이렇게 진행해 주세요."
마무리 시"오늘 수고 많으셨습니다. 각 팀에서 정리 완료되면 알려주세요."

9 기획팀이 맡지 않는 일

기획팀은 전체 조율을 하되, 아래 사항은 각 전담 팀이 맡는다.

  • 초청 가족 접수·개인정보 기록 → 새가족팀
  • 주차·시설 안전 현장 대응 → 차량관리팀
  • 찬양 리허설·예배 진행 세부 → 예배찬양팀
  • 음향·영상 기술 조작 → 방송팀
  • 식사 조리·배식 → 주방팀
  • 사진 촬영·파일 관리 → 교육팀

10 비상 상황 대응

상황대응
특정 팀 팀장 미도착부팀장 또는 해당 팀원에게 연락, 필요 시 기획팀 인원이 임시 지원
초청 가족이 예상보다 크게 초과주방팀에 추가 수량 요청, 사진관 운영 시간 연장 판단, 좌석 추가 배치
장비 고장 (음향·영상)방송팀에 확인, 복구 시간 판단 후 예배 진행 방식 조정
팀 간 역할 충돌현장에서 즉시 중재, 담임목사님 판단이 필요하면 보고
안전 사고 발생119 신고 우선, 차량관리팀과 현장 통제, 담임목사님 보고
