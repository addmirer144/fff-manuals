창립 72주년 감사예배 및 홈커밍
2026년 06월 07일(주일) 오전 11시 | 선린교회 | 담당: 이미숙 집사
"초청 가족이 환대받는 식탁을 준비한다"
주방팀은 맛있는 식사를 준비할 뿐 아니라, 초청 가족이 "이 교회는 따뜻한 곳이다"라고 느낄 수 있는 식탁 경험을 만든다.

애찬 운영 3원칙

  • 초청 가족이 줄에서 혼자 서지 않는다. → 초청자(교인) 또는 새가족팀이 동행
  • 초청 가족이 식탁에서 혼자 앉지 않는다. → 목장 리더 또는 교인이 함께 앉도록 사전 조율
  • 목장 리더가 자연스럽게 인사한다. → 목장 연결이 가능한 경우 식사 자리에서 첫 만남

4 사전 준비 체크리스트

D-7 (1주 전)

  • 메뉴 확정 및 예상 인원 수 확인 (기획팀과 조율)
  • 식재료 구매 목록 작성 및 예산 확인
  • 초청 가족 예상 인원 확인 (새가족팀 접수 현황)
  • 초청 가족 좌석 배치 방안 결정: 별도 테이블 구분? 또는 교인과 자연스럽게 섞기? 목장 리더 / 새가족팀이 함께 앉을 수 있는 좌석 배치
  • 아동 / 어르신 특별 배려 메뉴 필요 여부 확인
  • 식기 / 식탁보 / 수저 수량 확인

D-1 (전날)

  • 식재료 사전 준비 (손질 가능한 것)
  • 식기 / 수저 수량 최종 확인
  • 식탁 배치 확인 (3층 식당)
  • 주방 기기 점검 (가스레인지, 밥솥, 냉장고 등)
  • 주방팀 인원 / 역할 배분 확인

5 시간대별 상세 동선

10:00~11:00 — 주방 준비 / 조리

  • 주방팀 3층 주방 집결
  • 식탁 / 의자 배치 확인 (차량관리팀 지원 필요 시 요청)
  • 식탁보 / 수저 / 접시 세팅
  • 조리 시작 — 메뉴별 시간 역순 배치
  • 음료 / 물 준비
  • 초청 가족 좌석 위치 표시 (필요 시 — 새가족팀과 확인)
  • 기획팀에서 전달한 예상 인원 수 최종 확인

11:00~12:00 — 조리 마무리 / 배식 준비

  • 메인 요리 마무리
  • 배식 동선 세팅 (줄 서기 → 배식 → 좌석)
  • 국 / 반찬 / 밥 배식 순서 확인
  • 식사 안내 표지판 설치 (메뉴 안내)
  • 배식 인원 배치 확인
  • 위생 점검 (앞치마, 위생장갑, 집게 등)

12:00~12:30 — 배식 시작

  • 예배 종료 후 교인 / 초청 가족 3층 이동 시작
  • 배식 시작 — 안내팀이 3층 입구에서 동선 안내
  • 초청 가족이 줄에서 혼자 서지 않는지 확인
  • 혼자 서 있는 분 발견 시: "함께 식사하실 분이 곧 오실 겁니다. 이쪽에서 편하게 기다려 주세요."
  • 아동 / 어르신 우선 배식 배려
  • 음식이 부족해 보이면 기획팀에 즉시 보고

12:30~13:00 — 식사 시간

  • 추가 배식 필요 시 대응 (밥 / 국 추가)
  • 초청 가족 식탁에 목장 리더 / 교인이 함께 앉았는지 확인
  • 빈 그릇 수거 시작 (식사 마친 테이블부터)
  • 후식 / 음료 제공 (준비된 경우)

13:00~13:30 — 뒷정리

  • 잔여 음식 정리
  • 식기 / 수저 세척
  • 식탁 / 의자 정리
  • 주방 청소 (가스 밸브, 환풍기 등 확인)
  • 쓰레기 분리수거
  • 3층 원상복구 확인
  • 잔여 식재료 처리 방안 결정

6 현장 멘트 모음

상황멘트
식사 안내"식사가 준비되어 있습니다. 이쪽으로 오시면 됩니다."
배식 시"더 필요하시면 말씀해 주세요."
초청 가족에게"오늘 와 주셔서 감사합니다. 맛있게 드세요."
혼자 서 계신 분"이쪽에서 편하게 앉아 계시면 됩니다. 곧 함께 식사하실 분이 오실 겁니다."
마무리 시"식사 맛있게 하셨나요? 감사합니다."

7 주방팀이 맡지 않는 일

아래 사항은 해당 팀이 맡는다. 문의를 받으면 담당 팀으로 연결한다.

  • 초청 가족 명단 / 접수 → 새가족팀
  • 식사 동선 안내 (3층 입구) → 안내팀
  • 초청 가족 옆에 앉을 교인 조율 → 새가족팀 / 목장 리더
  • 식탁 / 의자 대량 이동 → 차량관리팀 지원
  • 카페 쿠폰 지급 → 새가족팀
