2 핵심 원칙

  • 보이고 들리는 모든 것을 방송팀이 책임진다
  • 화면에 표시되는 모든 텍스트에서 교회 내부 용어를 점검하고, 초청 가족이 이해할 수 있는 표현을 사용한다
  • 유튜브 스트리밍으로 온라인 참여자도 함께 예배할 수 있도록 한다
  • 사진관 파일 전달 채널을 사전에 확보하여 교육팀을 지원한다

5 방송팀 미션

담당: 김정원 집사, 한민석 목사 | 최소 인원: 2명 (음향 1 + 영상 1)

방송팀은 예배의 기술적 기반을 담당한다. 음향·영상·자막·스트리밍이 끊김 없이 동작하도록 하고, 화면에 나오는 모든 텍스트가 초청 가족에게 낯설지 않은지 점검한다.

6 사전 준비 체크리스트

D-7 (1주 전)

  • 설교 + 꽃 전달 순서 반영한 큐시트 갱신
  • 프로프리젠터 자막 파일 제작 (찬양, 성경 본문, 안내 문구)
  • 초청 영상 파일 수신 및 확인 (홍보팀에서 전달)
  • 화면에 표시되는 텍스트 중 교회 내부 용어 점검
  • 가족사진 다운로드 경로 확보 방법 확인 (교육팀과 조율)

D-1 (전날)

  • 프로프리젠터 파일 최종 점검
  • 유튜브 스트리밍 URL 생성 및 공유
  • 예배 후 안내 슬라이드 준비 (사진관·애찬·쿠폰 안내)
  • 여분 마이크·배터리 준비
  • 방송실 인원 확정 (최소 2명: 음향 1 + 영상 1)

7 시간대별 상세 동선

10:00~10:30 — 장비 점검·리허설 지원

  • 방송팀 전원 사랑채플 방송실 집결
  • 전체 장비 전원 ON — 음향 믹서, 프로젝터, 카메라, PC
  • 마이크 점검: 설교용, 찬양 보컬, 사회자 (무선 마이크 배터리 확인)
  • 프로프리젠터 슬라이드 순서 확인 — 첫 화면부터 마지막까지 한 번 통과
  • 초청 영상 재생 테스트
  • 예배찬양팀 리허설 시 음향 밸런스 조절
  • 유튜브 스트리밍 설정 확인 (제목, 썸네일, 공개 설정)

10:30~10:55 — 최종 점검·대기

  • 리허설 종료 후 음향 밸런스 최종 고정
  • 자막 전환 순서 최종 확인 (큐시트 기준)
  • 유튜브 스트리밍 시작 (10:55 또는 기획팀 지시)
  • 방송실 인원 위치 확인 (음향·영상 각 1명 이상)
  • 긴급 연락 수단 확인 (무전기 또는 메시지)

11:00~12:00 — 예배 중 실시간 운영

  • 찬양 자막 전환 — 약간 선행하여 회중이 따라올 수 있도록
  • 설교 본문 자막 적시 표시
  • 꽃 전달 순서 시 카메라 앵글 조정 (전달 장면 중심)
  • 기도카드 안내 슬라이드 표시
  • 초청 영상 상영 시점에 맞춰 전환
  • 음향 레벨 지속 모니터링 — 하울링·잡음 즉시 대응
  • 유튜브 스트리밍 상태 확인 (끊김 없는지)

12:00~12:10 — 예배 종료·안내 슬라이드

  • 폐회 후 안내 슬라이드 송출:
    • 가족사진: 4층 소망채플
    • 식사: 3층 애찬 장소
    • 카페 쿠폰: 접수 시 수령
  • 유튜브 스트리밍 종료
  • 단체사진 촬영 시 음향 지원 (필요 시 마이크 제공)

12:10~13:30 — 정리·파일 전달

  • 장비 전원 OFF, 케이블 정리
  • 마이크 배터리 보관
  • 가족사진 파일 전달 지원 (교육팀과 채널 확인)
  • 예배 영상 유튜브 편집·업로드 일정 확인
  • 방송실 원상복구

9 방송팀이 맡지 않는 일

아래 사항은 각 전담 팀이 맡는다.

  • 찬양 선곡·인도 → 예배찬양팀
  • 초청 영상 촬영·편집 → 홍보팀 (김도현 전도사 촬영, 한민석 목사 편집)
  • 사진 촬영 → 교육팀
  • 예배실 좌석 안내 → 안내팀
  • 예배 후 동선 안내 → 안내팀
