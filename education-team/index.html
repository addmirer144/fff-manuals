"4층 소망채플 가족사진관을 운영한다"
초청 가족에게 "함께 찍은 가족사진"이라는 특별한 기념을 선물한다. 사진관의 준비부터 촬영, 파일 전달까지 전 과정을 관리한다.

5 사전 준비 체크리스트

D-7 (1주 전)

  • 배경천 설치 확인 (색상·크기·고정 방법)
  • 의자·소품 준비 (가족 인원별 배치 연습)
  • 조명 장비 점검 (스탠드 조명, 자연광 활용 방법)
  • 에어컨 작동 확인 (4층 여름철 온도 관리)
  • 우드프레임·4x6 인화 준비 여부 확인
  • 촬영 파일 전달 방법 확정 (USB, 클라우드, QR 다운로드 등)
  • 파일명 통일 규칙 확정 (예: FFF_가족명_001.jpg)
  • 촬영자 + 보조 1명 이상 확정

D-1 (전날)

  • 4층 소망채플 사진관 사전 셋업 (가능한 경우)
  • 배경천·의자·소품 배치 리허설
  • 카메라·메모리카드·배터리 충전 확인
  • 여분 메모리카드·배터리 준비
  • 초청 가족 우선 촬영 시간표 확인 (새가족팀 접수 양식과 연동)

6 시간대별 상세 동선

10:00~10:30 — 사진관 셋업

  • 교육팀 4층 소망채플 집결
  • 배경천 설치·고정 확인
  • 의자·소품 배치
  • 조명 설치 및 각도 조정
  • 에어컨 가동
  • 카메라 셋업 — 화이트밸런스, 노출 설정
  • 테스트 촬영 (스태프 촬영하여 화질·조명·배경 확인)
  • 촬영 대기 공간 확인 (4층 복도 또는 인근 공간)
  • 안내 사인 확인 (홍보팀 설치)
  • 기획팀에 셋업 완료 보고

10:30~11:00 — 최종 점검

  • 테스트 촬영 결과 확인 — 문제 있으면 조정
  • 새가족팀과 촬영 신청 가족 명단 공유 여부 확인
  • 촬영 순서 운영 방식 최종 확인
12:00~12:30 — 초청 가족 우선 촬영
12:30~13:00 — 일반 교인 가족 (희망자)
  • 촬영 흐름: 입장 → 소품 선택 → 포즈 안내 → 촬영(3~5컷) → 퇴장

11:00~12:00 — 예배 중

  • 예배 참여 (사진관 운영 불필요)
  • 11:50경 교육팀 1명 4층으로 이동하여 사전 준비 (조명 ON, 에어컨 확인)

12:00~12:30 — 초청 가족 우선 촬영

  • 예배 종료 후 사진관 운영 시작
  • 안내팀과 협력 — 4층으로 올라오는 가족 안내
  • 접수 시 촬영 신청한 초청 가족 우선 안내
  • 가족 입장 → 간단 인사: "가족사진 촬영해 드리겠습니다"
  • 소품 선택 안내 (원하는 경우)
  • 포즈 안내 → 3~5컷 촬영
  • "촬영이 끝났습니다. 사진은 이후에 전달해 드리겠습니다"
  • 다음 가족 안내
  • 대기줄이 길어지면 안내팀에 4층 대기 관리 지원 요청
  • 파일명 즉시 기록 (가족명 매칭)

12:30~13:00 — 일반 촬영 + 마무리

  • 초청 가족 촬영 완료 후 일반 교인 가족 촬영
  • 촬영 종료 시간 안내: "13시에 사진관을 마감합니다"
  • 촬영 완료 가족 수 기록

13:00~13:30 — 정리·파일 관리

  • 사진관 장비 정리 (카메라·조명·소품)
  • 배경천·의자 원상복구
  • 촬영 파일 백업 (메모리카드 → PC/클라우드)
  • 파일명 정리 — 통일 규칙에 맞게 재확인
  • 파일 전달 채널 통해 공유 시작 (또는 전달 일정 안내)
  • 촬영 명단 새가족팀·기획팀에 공유
  • 4층 소망채플 원상복구 확인

8 교육팀이 맡지 않는 일

아래 사항은 해당 팀이 맡는다. 문의를 받으면 해당 팀으로 연결한다.

  • 초청 가족 접수·명단 관리 → 새가족팀
  • 4층 이동 동선 안내 → 안내팀
  • 사진관 입구 데코 → 홍보팀
  • 사진관 가구·배경천 운반 설치 → 차량관리팀 지원
  • 사진 파일 영상 편집 → 방송팀 (전달 채널만 확보)
