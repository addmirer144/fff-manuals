"안전한 주차와 시설을 관리한다"
차량관리팀은 교회 시설 전반의 안전과 주차 질서를 책임진다. 초청 가족이 도착부터 귀가까지 안전하게 이동할 수 있도록 돕고, 다른 팀의 설치 / 운반 작업을 지원한다.

핵심 목표미출석 가족 회복, 관계적 환대, 사후 관리 연결

2 핵심 원칙

  • 안전한 주차와 시설 관리를 책임진다.
  • 초청 가족이 교회에 도착하는 순간부터 안전하고 편안하게 느낄 수 있도록 한다.
  • 시설 문제는 즉시 대응하되, 안전이 최우선이다.
  • 다른 팀의 설치 / 이동 지원 요청에 적극 협력한다.

5 사전 준비 체크리스트

D-7 (1주 전)

  • 주일 차량 노선 및 주차장 수용량 확인
  • 예상 차량 증가분 판단 (초청 가족 동반)
  • 인근 임시 주차 가능 공간 확인
  • 1층 포토존이 차량 진입 / 보행 동선을 막지 않는지 확인 (홍보팀과 조율)
  • 4층 소망채플 사진관 설치에 필요한 물품 확인 (교육팀과 조율)
  • 각 층 시설 점검 (화장실, 엘리베이터, 계단 조명, 에어컨 등)

D-1 (전날)

  • 주차장 정리 (불필요한 물건 제거)
  • 4층 사진관 설치 지원 (배경천 / 의자 / 소품 운반 — 교육팀 요청 시)
  • 주차 안내 표지판 준비
  • 비상 장비 점검 (소화기, 비상등, 구급약품)

6 시간대별 상세 동선

10:00~10:30 — 주차장 정리 / 설치 지원

  • 차량관리팀 주차장 집결
  • 주차장 공간 확인 — 예상 차량 대비 여유 공간 확보
  • 주차 안내 표지판 설치
  • 각 층 시설 순회 점검: 화장실 청결 / 비품 확인, 엘리베이터 정상 작동 확인, 계단 조명 확인, 에어컨 가동 확인 (사랑채플, 3층 식당, 4층 소망채플)
  • 교육팀 요청 시 4층 사진관 설치 지원 (운반 / 고정)
  • 홍보팀 요청 시 대형 설치물 운반 지원
  • 기획팀에 시설 점검 완료 보고

10:30~11:00 — 주차 안내 / 승하차 보조

  • 초청 가족 차량 도착 — 주차 안내 시작
  • 어르신 / 장애인 / 아동 동반 차량은 입구 가까이 안내
  • 승하차 시 안전 보조
  • 주차장 만석 시 임시 주차 공간 안내
  • 이중주차 발생 시 연락처 확인하여 정리

11:00~12:00 — 예배 중

  • 주차장 상시 모니터링 (늦은 차량 안내)
  • 시설 이상 발생 시 즉시 대응 (정전, 수도, 에어컨 등)
  • 엘리베이터 작동 상태 확인 (예배 후 대량 이동 대비)

12:00~13:00 — 예배 후

  • 4층 ↔ 3층 이동 시 엘리베이터 / 계단 안전 확인
  • 복도 / 계단에서 혼잡 시 안전 관리
  • 시설 문제 발생 시 즉시 대응
  • 주방팀 요청 시 가구 이동 지원

13:00~13:30 — 출차 / 정리 / 원상복구

  • 귀가 차량 출차 안내 — 안전한 출차 순서 관리
  • 이중주차 차량 정리
  • 주차 안내 표지판 철거
  • 각 층 시설 원상복구 확인: 4층 사진관 철거 지원 (교육팀 요청 시), 3층 식탁 / 의자 원상복구 (주방팀 지원), 각 층 조명 / 에어컨 OFF, 화장실 최종 점검
  • 주차장 최종 정리
  • 기획팀에 원상복구 완료 보고

8 차량관리팀이 맡지 않는 일

아래 사항은 해당 팀이 맡는다. 문의를 받으면 담당 팀으로 연결한다.

  • 초청 가족 접수 / 안내 → 안내팀 / 새가족팀
  • 예배실 좌석 안내 → 안내팀
  • 홍보물 디자인 / 제작 → 홍보팀
  • 사진 촬영 → 교육팀
  • 식사 조리 / 배식 → 주방팀
